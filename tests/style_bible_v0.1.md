# 《123罗德岛》样图视觉风格规范

版本：v0.1（生成前基线）。分析日期：2026-09-17。目标：迁移稳定的绘画与叙事语法，重新设计角色，不复用具体角色的发型、配色、服饰、兽耳、角、光环或标识组合。

## 资料范围与可信度

来源为 `../private_assets/source/123罗德岛_官方原图/`，共 339 个篇章目录、683 张图片，SHA-256 均不相同；679 张为 600×1636 竖版漫画，4 张为周年宣传图。已按自然篇章顺序通过 29 张总览板逐一浏览全部图片；入选分镜另以原始像素裁切复核。总览浏览用于判断画法和用途，不等于逐字校对全部台词。完整路径、尺寸、哈希见 `../analysis/inventory.json`，分类见 `../analysis/classification.csv`。文中比例和数量是目测后给生成使用的操作区间，不是对全部样本的精确测量统计。

宣传图 ID 130、279、432、589 单独标记：它们可补充全身/群像画法，但不作为常规四格版式的依据。少数梗图中的写实脸、复杂武器特写、界面截图、光效或强透视不代表常态。

## 核心优先级

1. 大头短身的轮廓与低位五官。
2. 深色明确线稿、发块、平涂与有限硬边阴影。
3. 表情可读性、角色之间的视线和反应关系。
4. 背景退后，文字和道具服务笑点。

“Q版、可爱、日系”不足以约束风格。头大不等于婴儿比例，平涂不等于完全无阴影；耳朵、光环、制服属于角色设计，不是必须继承的风格。

## 页面与场景规则

典型源页的四个主框约为 x=88–563、y=60–410 / 440–790 / 820–1171 / 1200–1552。这里记录的是样图模板的近似几何，不要求新作品复制它；可迁移的是横格、白沟槽、阅读顺序和末格反应。气泡常位于上部，人物落在中下部，但前景大头和动作格经常打破对称。

室内先确定一条桌沿/地面线、一个门窗/柜体，再安排人物；室外先确定天空与地面两个色块，再加一棵树或一段建筑轮廓。不要把环境做成比人物更写实的插画。多人对话要逐个确认谁说话、谁听、谁反应；不是把四个正面头像平均排开。

## 精选参考及使用方式

每组 4 张，16 张来源页互不重复。裁片保留原始画面，未改写原图内容；标签在 contact sheet 的留白区。源路径、裁切坐标和选取理由见 `../analysis/references.json`。所有编号都是本项目 inventory ID，不等于篇章编号。P1–P4 指自上而下的主分镜；P0 指整页。

| 组 | 精选 ID / 分镜 | 用途 |
|---|---|---|
| 核心 | 026-P1、099-P1、145-P1、628-P3 | 跨深浅发色、冷暖背景、平静与兴奋状态确认共同画法 |
| 人物 | 115-P2、538-P2、567-P1、535-P2 | 短肢、不同体型、衣服压缩、行走轮廓；非人型仅用于形体压缩，不要求新人物继承物种 |
| 表情 | 050-P4、117-P4、184-P3、292-P4 | 惊讶、崩溃、含泪、失控大笑；分别使用，不同时灌入一个人物 |
| 构图 | 137-P0、198-P2、236-P1、438-P1 | 重复机位、俯视群体、室外层次、室内近景 |

优先使用 `../private_assets/derived/contact_sheets/core.jpg`，按任务加 `../private_assets/derived/contact_sheets/character.jpg`、`../private_assets/derived/contact_sheets/expression.jpg` 或 `../private_assets/derived/contact_sheets/composition.jpg`。单场景通常用核心加一个专项组就够；多图越多，角色元素和场景内容越容易互相污染。需要更清楚的单个构图时，直接使用 `../private_assets/derived/reference_crops/` 中对应裁片；137 整页不要只看缩略板。

## 生成提示词基线

> 原创日常喜剧漫画，约 2–2.6 头身的短身体，宽圆头与浅圆下巴，低位大椭圆眼或半睁眼，粗上眼睑，小线嘴，省略鼻梁。头发由少量大块刘海与侧发组成，一层底色、一层硬边阴影、1–2 个椭圆亮斑。近黑清晰轮廓，外粗内细；团状手、短块状鞋、服装只留主要结构。平涂，浅色低对比背景结构线，局部网点。白色黑边气泡，读图关系明确。按本次剧情指定景别、站位、表情和必要道具。

约束：不复制样图角色的发型服装组合；不出现来源 LOGO；不加写实解剖、尖长下巴、长腿、逐根发丝、虹膜花纹、软体积面部阴影、金属般头发高光、景深摄影效果或 3D 玩具材质。阴影与表情允许有明确情境例外，不以全面删除细节代替风格判断。

## 测试计划与验收

使用内置 image_gen，5 次独立生成：图书馆全身、茶水间双人、修理员惊讶大头、公园四人、雨天四格。统一风格基线、改变场景和景别；这是跨场景压力测试，不是控制变量实验，不能据此估计统计成功率。提示词见 `../prompts/`，输入引用见 `generation_manifest.json`。

逐张观察：比例、脸/眼、发块与高光、手脚/服装、线与色、阴影、背景、构图/文字。用“轻微 / 明显 / 严重”描述偏移，不用无依据的精确相似度分数。测试结果与修订将在生成后补入本文件，并保留本基线供对照。
